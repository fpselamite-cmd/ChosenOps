# Vehicle pictures

Drop a picture here and every kit with that car shows it.

- Name the file after the car, lower case, dashes for spaces: `Sultan RS` → `sultan-rs.png`, `Bati 801` → `bati-801.png`.
- PNG with a transparent background, car side-on facing right, about 600×250. The app adds the gold glow itself, so keep them plain for a uniform look.
- Cars without a picture get a gold outline for their class.
