# Strain logos

Each strain loads its logo from this folder. The file name must match the strain id exactly:

| Strain          | File                    |
|-----------------|-------------------------|
| Acapulco Gold   | `acapulco.png`          |
| Columbian Gold  | `columbian.png`         |
| Dosidos         | `dosidos.png`           |
| Skunk1          | `skunk1.png`            |
| OGKush          | `ogkush.png`            |
| Pure Afghani    | `afghani.png`           |
| Rainbow Belts   | `rainbow.png`           |
| Northern Lights | `nl.png`                |
| Lemonskunk      | `lemonskunk.png`        |
| Gelato41        | `gelato41.png`          |

- Square PNGs around 256×256 work best (keep them small, they load on every page view).
- A missing file shows a "No Logo" placeholder instead of breaking the page.
- Uploading a logo in **Admin → Strain Logos** overrides it in that browser only; the reset button goes back to the file here.

The header logo is `NoelOpsLogo.png` in the repo root.
